# FermatPlanes

Author: Benjamin Stanley Frohman (@BenFrohman).

Easy-arrow planes on the Fermat quartic fourfold

    X : z₀^4 + ⋯ + z₅^4 = 0 ⊂ ℙ^5

with ζ^4 = -1. This is **not** the Hodge conjecture.

Sister repos:
- [BenFrohman/HODGE](https://github.com/BenFrohman/HODGE) — fourfold Hodge sentence, guarded axiom, classical islands.
- [BenFrohman/NoetherLefschetz](https://github.com/BenFrohman/NoetherLefschetz) — very general high-degree hosts have no extra classes.

Copies remain under `Hodge/Attempt/` in HODGE. They are not imported by `Hodge.lean`.
